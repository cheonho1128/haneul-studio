# 하늘 스튜디오 (Haneul Studio) v0.3

윈도우용 개인 영상 편집기. Electron + FFmpeg.

## 실행 방법 (윈도우)
1. `HaneulStudio-0.2.0-win.zip` 압축을 풉니다.
2. 폴더 안의 `Haneul Studio.exe`를 실행합니다. (설치 필요 없음)
3. 처음 실행 시 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. (서명되지 않은 개인용 앱이라 나오는 안내입니다)

## v0.2 새 기능
- 타임라인에 시간대별 장면(필름스트립)과 소리 파형 표시
- 선택 도구(A) / 분할 도구(B: 클릭한 곳을 바로 자름), 왼쪽·오른쪽 클립 한꺼번에 선택([ / ]), 여러 클립 함께 옮기기·지우기
- 효과 11종: 줌 인/아웃, 흔들림, 글리치, 비네팅, 필름 그레인, 모자이크, 플래시, 색 반전, 좌우/상하 반전
- 크로마키 (초록·파란 배경 지우기)
- 클립 사이 전환: 디졸브, 검은 화면, 흰 화면, 슬라이드 4방향 (클립 사이 + 버튼)
- 텍스트 등장 애니메이션: 위로·아래로·왼쪽·오른쪽, 타자기
- 정지 화면 넣기, 복사·잘라내기·붙여넣기, 빈자리 당겨서 삭제
- 필터 2종 추가 (필름, 사이버)
- 단축키를 한글 입력 상태에서도 사용 가능, F1로 단축키 목록 보기

## 1단계 기능
- 미디어 가져오기: 영상/사진/음악, 파일을 창에 끌어다 놓기 가능
- 타임라인: 여러 영상·텍스트·오디오 트랙, 드래그로 이동, 양 끝을 끌어 길이 조절, 자석(스냅), 확대/축소
- 편집: 분할(S), 앞/뒤 자르기(Q/W), 복제(Ctrl+D), 삭제, 실행 취소/다시 실행
- 화면: 크기·위치·회전·불투명도 (미리보기에서 직접 끌어서 이동, 오른쪽 아래 모서리로 크기 조절)
- 필터 8종 + 밝기·대비·채도·흐림 보정
- 속도 0.1x ~ 10x (소리 포함)
- 볼륨, 오디오 분리, 배경음악
- 전환: 페이드 인/아웃 (위 트랙에서는 디졸브)
- 텍스트: 템플릿 8종, 글꼴·색·테두리·배경·그림자·정렬
- 자막: 빠른 입력, SRT 가져오기/내보내기, 스타일 일괄 적용
- 화면 비율: 16:9, 9:16, 1:1, 4:5, 4:3, 21:9 / 24·30·60fps
- MP4(H.264 + AAC) 내보내기, 화질 선택
- 프로젝트 저장/열기 (.hsproj)

## 단축키 (F1을 누르면 앱에서도 볼 수 있어요)
Space/K 재생 · A 선택 도구 · B 분할 도구 · S 또는 Ctrl+B 재생헤드에서 분할 · Q/W 앞/뒤 자르기 · [ / ] 왼쪽/오른쪽 모두 선택 · Ctrl+A 모두 선택 · Delete 삭제 · Shift+Delete 당겨서 삭제 · Ctrl+C/X/V · Ctrl+D 복제 · Ctrl+Z/Y 되돌리기/다시 · ←/→ 1프레임 (Shift 1초) · J/L 5초 · Alt+←/→ 클립 1프레임 이동 · Shift+Z 전체 보기 · T 텍스트 추가 · Ctrl+S 저장 · Ctrl+E 내보내기

## 개발
```
npm install
npm start          # 실행
npm test           # 내보내기 엔진 테스트
npm run dist:win   # 윈도우 zip 빌드 (리눅스에서 빌드 시 npm_config_platform=win32 로 ffmpeg 재설치)
```

## 앱 안 업데이트 (개발자용)
앱은 `https://raw.githubusercontent.com/cheonho1128/haneul-studio/main/updates/latest.json`을 확인합니다.
1. `package.json`의 version을 올리고, `CHANGELOG-latest.txt`에 바뀐 점을 적습니다.
2. `npm run bundle` → `updates/update-<버전>.json`, `updates/latest.json` 생성
3. 커밋 후 main에 push 하면 앱의 "업데이트" 버튼에 나타납니다.
Electron이나 FFmpeg를 바꿔야 할 때만 `node tools/make-update.js <새 shell 버전>`으로 minShell을 올리고 전체 zip을 새로 배포합니다.
